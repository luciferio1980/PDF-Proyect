PDFForge Alpha 0.2.5
Independent professional PDF editor

Como usarlo
-----------
1. Extrae TODO el zip a una carpeta (no abras el .exe desde dentro del zip).
2. Si Windows marca el zip como descargado de Internet:
   clic derecho en el zip > Propiedades > Desbloquear > Aceptar,
   y vuelve a extraerlo.
3. Entra en la carpeta PDFForge y haz doble clic en "Abrir PDFForge.bat"
   (o en PDFForge.exe).
4. Si aparece "Windows protegio tu PC": Mas informacion > Ejecutar de todas formas.
5. Se abre el menu de inicio: Editar PDF o Firmar PDF.

Editar PDF
----------
- Clic en una linea para seleccionarla (inspector a la derecha).
- Doble clic o F2 para editar. El texto anterior se tapa al escribir.
  Enter confirma y sustituye la linea (no se pinta encima).
- Cambia tamano y color en el inspector y pulsa "Apply to PDF".
- Add text: activa el boton, clic en la pagina, escribe.
- File > Save guarda el PDF reescrito (no es un recuadro blanco).

Firmar PDF
----------
- Subir imagen, dibujar, o elegir una firma guardada (maximo 8).
- Ajusta el tamano (puntos) antes de colocarla, o despues con las esquinas.
- Clic en la pagina para colocar UNA firma. Para firmar otra vez:
  Inicio > Firmar PDF.
- Clic en la firma: recuadro de seleccion. Borrar firma o tecla Supr.
  Clic fuera del recuadro: se deselecciona y ya no se puede borrar
  hasta que vuelvas a picarla.
- Guardar firma / Eliminar firma guardada en el panel derecho.
- Save escribe la firma como objeto de imagen en el PDF.

Paginas
-------
- Rotar pagina, insertar pagina en blanco, borrar pagina, insertar otro PDF.

Que puedes probar tambien
-------------------------
- Zoom: Ctrl + rueda del raton
- Buscar: escribe 1.250,00 y pulsa Enter
- Guardar copia: File > Save copy (no pisa el original si no has editado)

Si no arranca
-------------
Esta carpeta debe contener PDFForge.exe, pdfium.dll, Qt6Core.dll,
platforms\qwindows.dll, vcruntime140.dll y msvcp140.dll juntas.

Requisitos
----------
Windows 10/11 de 64 bits.
El procesamiento es local: no se suben documentos.
