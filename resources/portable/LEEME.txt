PDFForge Alpha 0.1
Independent professional PDF editor

Como usarlo
-----------
1. Descomprime esta carpeta donde quieras.
2. Haz doble clic en PDFForge.exe (o en "Abrir PDFForge.bat").
3. Se abre un PDF de prueba automaticamente.
4. Tambien puedes arrastrar otro PDF sobre PDFForge.exe,
   o usar Archivo > Abrir.

Que puedes probar
-----------------
- Zoom: Ctrl + rueda del raton, o los botones Zoom + / -
- Paginas: miniaturas a la izquierda, o RePag / AvPag
- Rotar: botones Rotate CW / CCW
- Buscar: escribe 1.250,00 y pulsa Enter
- Guardar copia: File > Save copy (no pisa el original)

Que no esta en esta alpha
-------------------------
Todavia no se puede editar el texto del PDF.

Requisitos
----------
Windows 10/11 de 64 bits.
Las DLL de Qt y el runtime de Visual C++ van en esta carpeta.
El procesamiento es local: no se suben documentos.
